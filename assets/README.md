## 素材规范

### 角色立绘
- 格式：PNG（透明背景）
- 尺寸：建议 800×1200px 或同比例
- 风格：二次元，参考《重返未来1999》

### Q版序列帧
- 格式：PNG（透明背景）
- 尺寸：建议 128×128px 每帧
- 动画状态：idle(2帧), attack(3-4帧), skill(4-5帧), ultimate(5-6帧), hit(2帧)
- 帧率：8-12fps

### 地图背景
- 格式：JPG 或 WebP
- 尺寸：1920×1080px 或更大（支持滚动）

### 战斗特效
- 格式：PNG 序列帧或 sprite sheet
- 尺寸：按效果类型调整

## 当前状态

所有素材均为占位阶段，由 CSS/Canvas 绘制临时图形。
待角色设定确定后，将逐步替换为正式美术素材。
