# 未定之旅

> 网页二次元回合制 RPG · 技术预览版 v0.7.0

## 技术栈

- **前端**：纯 HTML5 + Canvas + 原生 JavaScript（零框架依赖）
- **后端/数据库**：Supabase（免费版，PostgreSQL + RPC）
- **部署**：GitHub Pages（静态托管）
- **美术**：CSS/Canvas 占位符（后期替换为二次元立绘 + Q版战斗序列帧）
- **音频**：暂未实现

## 游戏系统

### 战斗系统
- 回合制，速度条驱动行动顺序
- 四人编队
- 大招在角色回合内释放（不可插队）
- 元素克制（金→木→土→水→火→金，克制 +20% / 被克制 -15%）
- 弱点系统待定

### 共鸣系统
- 同元素角色 ≥ 2 人 → 一阶共鸣（攻击力 +10%，元素力回复 +15%）
- 同元素角色 = 4 人 → 二阶共鸣（攻击力 +25%，元素力回复 +30%，共鸣技强化）
- 队伍中最多同时存在两种元素共鸣
- 角色倒下时共鸣动态重新计算

### 元素力系统
- 独立于大招能量的充能资源
- 普攻回复 15 点元素力（共鸣增益额外加成）
- 元素技消耗 25 点，共鸣技消耗 30/45 点（按阶数）

### 技能体系
- **普攻**：仅消耗本回合行动机会，回复元素力
- **元素技**：消耗一定元素力 + 本回合行动机会
- **共鸣技**：需激活共鸣，消耗元素力（一阶30/二阶45），二阶为强化版
- **大招**：消耗100能量（独立能量条）

### 剧情地图
- 节点图系统，多故事线分支
- 剧情对话 + 战斗关卡 + 选择分支
- 云端存档

### 角色与抽卡
- 常驻池 + 限定池
- SSR 1.6% / SR 13% / R 85.4%
- 90 抽保底 SSR，10 抽保底 SR

## 文件结构

```
├── index.html          # 入口页面
├── js/
│   ├── engine.js       # 核心引擎（场景管理、渲染、输入、资源加载）
│   ├── battle.js       # 回合制战斗系统（含共鸣/元素力）
│   ├── story.js        # 剧情/地图/关卡管理
│   ├── save.js         # Supabase 云端存档
│   ├── gacha.js        # 抽卡系统
│   ├── growth.js       # 角色养成系统（升级/突破/技能）
│   ├── characters.js   # 角色图鉴 & 编队管理
│   ├── ui.js           # 所有场景 UI 渲染
│   └── main.js         # 游戏入口 & 初始化
├── assets/             # 美术资源（占位，后期填充）
│   ├── characters/     # 角色立绘 & Q版序列帧
│   ├── maps/           # 地图背景
│   └── battle/         # 战斗特效
├── game_schema.sql     # Supabase 数据库建表脚本
└── README.md
```
